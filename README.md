# 📌 Overview

MAYA AI Voice Assistant is an intelligent desktop assistant developed using Python. It allows users to interact with their computer using voice commands and perform various tasks such as searching the web, sending emails, checking weather updates, opening applications, controlling system settings, taking screenshots, and answering general questions using Google Gemini AI.

The project combines Speech Recognition, Text-to-Speech, Artificial Intelligence, and Desktop Automation into a single application with an interactive graphical user interface.

# 🔒 Privacy

MAYA only processes information required to execute the requested command.

The application may temporarily process:

- Voice Commands
- Search Queries
- Weather Requests
- AI Questions
- Email Details (when sending emails)

No voice recordings are permanently stored.

Sensitive credentials should be stored using a `.env` file.

---

# ⚠ Security

Never upload the following to GitHub:

- API Keys
- Gmail Passwords
- App Passwords
- .env file

Use environment variables instead.
